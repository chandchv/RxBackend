About Appointment Types

Appointment types allow you to categorize and manage different kinds of appointments. Each type:

  • Has a unique color for easy identification in the calendar
  • Defines a standard duration (in minutes)
  • Can include a description for additional information

Use these types to organize your schedule and improve efficiency.
